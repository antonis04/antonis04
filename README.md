**`Java Backend Developer · Spring Boot · Process orchestration (BPMN)`**

<p align="left">👨🏻‍💻 I'm a <strong>Java Backend Developer</strong> who delivers business processes end to end: I gather requirements directly with the client, model the process in <strong>Camunda 7 (BPMN)</strong>, implement every stage in <strong>Spring Boot</strong>, deploy it and support it in production. Day to day I work with <strong>Java, Spring Boot, PostgreSQL, Kafka, Keycloak, Docker and Kubernetes</strong> on process-orchestration and document-management systems for public-sector and banking clients.</p>
